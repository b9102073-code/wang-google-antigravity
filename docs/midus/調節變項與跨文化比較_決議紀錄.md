# 新增調節變項與跨文化比較：實測結論與決議紀錄

日期：2026-11-04　｜　資料來源：MIDUS 2/3 四個核心 SPSS 檔（M2P1、M2P3 BTACT、M3P1、M3P3 BTACT）
模型設定：暴露定義 B（任一波便祕）、結果 `C3TCOMP`、基線 `B3TCOMPZ1` 校正、分析計畫 §5.5 全部共變項、以 `M2FAMNUM` 叢集穩健 SE。完整案例 N = 2,028／暴露 188。

> 本檔只記錄彙總結果與變項名，不含任何受試者層級資料。原始 `.sav` 與分析輸出均不納入版本控管。

## 1. 四類調節變項的實際變項名

| 教授指定的概念 | MIDUS 2 變項 | 說明 |
|---|---|---|
| 學習指標 | `B1SA33A`–`B1SA33F` | SA33 認知活動頻率 6 題（閱讀／文字遊戲／紙牌／**課程演講**／寫作／電腦）。`B1SA33D` 最接近「正式學習」。M3 僅剩 3 題且題號改為 `C1SA29A/B/D`。 |
| 同上（態度而非行為） | `B1SINTAG` | Personality in Intellectual Aging Context |

| 健康食品 | `B1SSPLMX`（任一）／`B1SSPLMN`（種類數）／`B1SA14A`（綜合維他命）等 | M3 魚油與「其他」後綴不同：M2 `N`／`H` → M3 `M`／`O` |

### 1.1 實測發現的量表重疊
`B1SPERSI` 與 `B1SSPCTR` 是**完全相同的數值（r = 1.000）**；`B1SREAPP` 與 `B1SCSCSP` r = 0.952；`B1SCHANG` 與 `B1SCSCAG` r = 0.900。9 個變項只有 6 個獨立構念。

### 1.2 缺值編碼陷阱（每一組都不同）
- 所有 `B1S` 自填題：`-1` = 無自填問卷（4,963 人中 922 人）
- SA33／SA30 頻率題：`8` = 拒答
- `B1SF28B`：`8` = 拒答、`9` = 不適用（未就業）
- OPS 六量表：`98` = 無法計算
- Brandtstädter 三量表與 `B1SINTAG`：`8` = 無法計算（**與 OPS 的 98 不同**）
- `B1SSPLMX`／`B1SSPLMN`／`B1SA14*`：僅 `-1`

## 2. 交互作用檢定：20 個檢定，BH 校正後無一成立（最小 q = 0.26）

未校正下 p < .05 者僅兩項，且**方向與保護假說相反**：
- 服用任何補充劑：交互 β = −0.183（SE 0.074, p = .013）。服用者 β = −0.109（p = .005）／未服用者 **＋0.063**（p = .32）
- 認知活動綜合指數：交互 β = −0.072（SE 0.037, p = .049）。高分組 β = −0.153（p = .007）／低分組 −0.015（p = .71）

三類變項（學習、運動、補充劑）同時出現「高儲備者關聯更強」的反向型態，推測反映單一的健康意識／症狀自我監測傾向，與既知弱點（控制 `B1SAMPLI` 後主效果 p = 0.051）一致。**不作為正向發現報告。**

## 3. 檢定力限制
以實測 SE 回推（α = .05 雙尾, power = 80%）：連續型調節最小可偵測 |β| ≈ 0.084 SD/SD、二分型 ≈ 0.196 SD，**皆大於主效果本身（−0.097 SD）**。陰性結果只能解讀為「未偵測到大的調節效果」。瓶頸是暴露病例僅 188–213 人，解法是增加病例（Refresher 1＋2）而非增加調節變項。

待查證：MIDJA 1 的症狀清單是否含便祕題；MIDJA 生物標記的 IL-6／CRP 確切變項名。兩者皆未經原始資料核實。
