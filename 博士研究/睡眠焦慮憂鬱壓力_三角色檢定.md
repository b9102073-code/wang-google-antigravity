# 睡眠、焦慮、憂鬱、長期壓力在「便祕→認知退化」中的角色：實測與文獻查證

日期：2026-11-07
程式：`MIDUS/scripts/sleep_anxiety_stress.py`、`sleep_anxiety_stress_supp.py`
原始輸出：`MIDUS/output/睡眠焦慮憂鬱壓力_實測輸出.txt`
主模型沿用既有規格：暴露＝定義 B（任一波便祕，`B1SA11K`／`C1SA11K`）；結果＝`C3TCOMP` 校正 `B3TCOMPZ1`；
§5.5 全共變項；`M2FAMNUM` 叢集 SE；完整案例 **N = 2,028／暴露 188**，基準主效果 **β = −0.070 (p = .036)**。
（插補版主報告值 −0.097 不變；本文所有比較都在同一完整案例樣本內進行，故差異純為共變項調整所致。）

## 一、一句話結論

**會跑出相關，但相關的位置不對。**

這四類因素與**便祕**的關聯幾乎全部成立（FDR 校正後仍顯著），
但它們與**九年後的認知表現**幾乎全部不成立（FDR 校正後無一顯著）。
混淆需要兩個條件同時成立，第二個條件在本資料中失敗，
因此**這四類都不是便祕—認知關聯的混淆因子**：
把它們全部放進模型，主效果從 −0.0740 變成 −0.0739（衰減 0.1%）。

| 角色 | 結論 | 論文定位 |
|---|---|---|
| 混淆因子 | **不成立**（衰減 −2.6% ~ +3.6%，方向還常是變強） | 寫成「已排除的替代解釋」，是有利證據 |
| 中介 | **不成立**；唯一看起來成立的那一條是同波假象 | 不可寫成機制路徑 |
| 調節 | **偵測不到**（19 個交互作用 FDR 後 q 全 > .45） | 與既有 20 個交互作用的陰性一致，歸為檢定力限制 |
| 反向路徑的替代解釋 | **不成立**（加入後反向效果反而更強） | 強化反向因果的討論 |

## 二、變項的操作化與回查原題結果

**回查 SAQ 原題後的三個必須交代事項：**

1. `B1SA11T` 的原題是 **"Anxiety, depression, or some other emotional disorder"**（12 個月內經歷或接受治療）。
   **焦慮與憂鬱在這一題裡是綁在一起的，無法分離**，且與「其他情緒障礙」混雜。不能當成焦慮的測量。
2. `B1SA11W` 的原題是 **"Chronic sleeping problems"**，與便祕題（k. "Being constipated all or most of the time"）
   **出自同一張 A11 清單**。
3. **`B1SCHRON` 的 27 題慢性病計數本來就包含 T（焦慮憂鬱）與 W（慢性睡眠問題）** —— 也就是說，
   睡眠問題與焦慮憂鬱**一直都已經部分在既有模型裡**。改用扣掉 T 與 W 的 24 題重算，
   主效果 −0.0701 → −0.0709，幾乎不動，所以這個重疊不影響任何結論。

### 睡眠（MIDUS 有真正可用的量表）
- **`B1SA61A`–`D`（M3 = `C1SA57A`–`D`）**：A61 四題失眠症狀（入睡困難／夜醒難再睡／早醒／日間不解乏），
  1 = Never ~ 5 = Almost always。取均分為主要睡眠指標（缺失 0.0%）。**這是四類裡測量品質最好的一個。**
- `B1SA10G`：過去 30 天入睡／維持睡眠困難頻率（已反轉）。
- `B1SA57A/B`（M3 = `C1SA53A/B`）：工作日睡眠時數。
  **陷阱：分鐘欄的 `98` 標籤寫 Refused，但有 2,283 人是只填小時沒填分鐘**，故有效小時時以 0 分補。
- `B1SA11W`：自陳慢性睡眠問題（盛行率 10.1%）。

### 焦慮（**這是本次最大的測量限制**）
- `B1PANXIE`（CIDI-SF 廣泛性焦慮連續分，0–10）：**4,834／4,963 人得 0 分，二分型只有 99 例。**
  在分析樣本中 mean = 0.105、SD = 0.773。**這是 12 個月的診斷篩檢，不是症狀嚴重度量表。**
- `B1PANXTD`（二分）：分析樣本中盛行率 1.8%（37 例）→ **檢定力極低，陰性結果幾乎不具資訊量。**
- `B1PPANIC`（恐慌症狀 0–6）、`B1SNEURO`（神經質 1–4）作為替代。
- **MIDUS Project 1 沒有 GAD-7、STAI 或任何焦慮症狀嚴重度量表。這一點必須在限制中寫明，
  不能用「焦慮無關」來下結論，只能說「以 CIDI-SF 診斷層級測量時偵測不到」。**

### 憂鬱（已在既有模型中）
- `B1PDEPRE`（CIDI-SF 憂鬱情緒＋失樂趣，0–7）＝ 既有共變項 `depre`，逐步調整第三步。
- `B1SNEGAF`（負向情緒，1–5）為新增，測量的是一般性負向情緒而非憂鬱症。

### 長期壓力（MIDUS **沒有** Perceived Stress Scale 複合變項）
Project 1 無 PSS。採多領域持續性壓力的 z 分平均（四項，缺失 0.1%）：
`B1SKINNE` 家庭張力、`B1SFDSNE` 朋友張力、反轉後的 `B1SG7` 付帳困難、`B1SDAYDI` 日常歧視。
另列 `B1SSPCRI` 配偶張力（**`9` = 無伴侶 962 人須設缺失**，故僅 78% 可用）
與 `B1SJCDS` 工作要求（**`99` = 未就業**，僅 74% 可用），不納入指數。
**M3 的編號有位移陷阱：付帳困難是 `C1SG9`（不是 `C1SG7`，`C1SG7` 在 M3 是「錢夠不夠」）。**

**共線性無問題**：所有新增因素 VIF 皆 ≤ 1.94（最高是負向情緒），
因素間最大相關 r = .550（神經質↔負向情緒）。
（註：指數與其四個分項不可同時放入，否則完全共線；更正後的 VIF 見程式輸出。）

## 三、實測結果

### 3.1 混淆的兩個必要條件 —— 第一個成立，第二個全部失敗

**a 路徑（便祕組 vs 非便祕組的因素差異，校正年齡性別教育）：大多成立。**

| 因素 | a 路徑 | FDR q |
|---|---|---|
| 自陳焦慮或憂鬱（A11t） | **+0.543 SD**, p < .0001 | **.0000 ✔** |
| 負向情緒 | **+0.391 SD**, p < .0001 | **.0001 ✔** |
| 失眠症狀（A61 均分） | **+0.298 SD**, p = .0005 | **.0029 ✔** |
| 恐慌症狀 | **+0.288 SD**, p = .0061 | **.0129 ✔** |
| 自陳慢性睡眠問題 | **+0.284 SD**, p = .0039 | **.0093 ✔** |
| 30 天入睡困難頻率 | **+0.268 SD**, p = .0007 | **.0032 ✔** |
| 長期壓力指數 | **+0.241 SD**, p = .0016 | **.0052 ✔** |
| 神經質 | **+0.239 SD**, p = .0009 | **.0035 ✔** |
| 配偶張力 | +0.226 SD, p = .016 | .029 ✔ |
| 日常歧視 | +0.218 SD, p = .0030 | .0082 ✔ |
| 家庭張力 | +0.206 SD, p = .017 | .029 ✔ |
| 短睡 < 6 小時 | +0.198 SD, p = .035 | .055 |
| **CIDI 憂鬱（既有共變項）** | **+0.143 SD, p = .108** | **.137（不顯著）** |
| **CIDI 焦慮連續** | **+0.037 SD, p = .703** | **.742（不顯著）** |
| **CIDI 焦慮診斷** | **+0.009 SD, p = .915** | **.915（不顯著）** |
| 睡眠時數 | −0.126 SD, p = .170 | .190 |

**關鍵對比：自陳式的「焦慮或憂鬱」差距 0.543 SD（最大的一項），
但結構式診斷工具測到的焦慮與憂鬱差距趨近於零（0.009–0.143 SD，皆不顯著）。**
這個落差本身就是一個發現：便祕組與非便祕組的差異集中在**自陳症狀報告**，
而不在**診斷層級的精神疾病**。它與既知弱點（控制症狀放大 `B1SAMPLI` 後 p = .051）指向同一件事，
應該與那一段寫在一起。

**b 路徑（因素對九年後認知的效果，校正基線認知＋全共變項）：FDR 校正後全部不成立。**

未校正 p < .05 僅四項，且效果量都極小：
負向情緒 −0.023 SD/SD (p = .032)、長期壓力指數 −0.023 (p = .023)、
付帳困難 −0.025 (p = .012)、日常歧視 −0.023 (p = .022)。
**FDR 校正後最小 q = 0.14，無一通過。** 睡眠的三個指標 b 路徑完全虛無（p = .37–.88）。

> **這是本次最重要的單一結果。** 在 MIDUS 這個中年樣本（平均 55.4 歲）、九年追蹤、
> 以 BTACT 多領域連續測驗為結果的設定下，**睡眠、焦慮與長期壓力都不預測認知變化**。
> 既然它們不影響結果變項，它們就不可能是便祕—認知關聯的混淆因子。

### 3.2 作為共變項加入 —— 主效果幾乎不動

| 加入 | N | 未加 β | 加入後 β | p | 衰減 |
|---|---|---|---|---|---|
| ＋睡眠（失眠症狀） | 2,027 | −0.0701 | −0.0703 | .036 | **−0.3%** |
| ＋睡眠（整組三項） | 2,016 | −0.0677 | −0.0688 | .042 | **−1.7%** |
| ＋焦慮（CIDI 連續） | 2,028 | −0.0701 | −0.0711 | .033 | **−1.4%** |
| ＋焦慮（GAD＋恐慌＋神經質） | 2,019 | −0.0750 | −0.0770 | .022 | **−2.6%** |
| ＋負向情緒 | 2,022 | −0.0736 | −0.0709 | .036 | +3.6% |
| ＋長期壓力（指數） | 2,025 | −0.0706 | −0.0693 | .040 | +1.8% |
| ＋長期壓力（四分項） | 1,996 | −0.0682 | −0.0668 | .048 | +2.1% |
| **＋四類整組同時加入** | 2,018 | **−0.0740** | **−0.0739** | **.031** | **+0.1%** |

**負號的衰減代表加入後效果變強。** 四類同時加入，點估計與 p 值都幾乎不變。

**憂鬱在既有模型中造成的衰減：+0.2%（−0.0703 → −0.0701）。**
這一點要據實寫出來：逐步調整第三步（＋BMI／慢性病／憂鬱）造成的衰減
（−0.089 → −0.072）**幾乎全部來自 BMI 與慢性病，憂鬱本身貢獻接近零**。
過去若把那一步籠統描述為「調整整體健康與憂鬱後衰減」，會讓讀者以為憂鬱有貢獻，應該改寫。

**其他結果同步確認穩定：**
- 持續型便祕 −0.165 (p = .0094) → 加入四類後 −0.149 (p = .0155)。
- 情節記憶 −0.111 (p = .047) → −0.123 (p = .028)；執行功能 −0.097 (p = .035) → −0.101 (p = .033)。

### 3.3 中介 —— 唯一看起來成立的那一條是同波假象

以定義 B 暴露做滯後中介，**只有 M3 負向情緒的 bootstrap 信賴區間排除 0**：
間接效果 −0.0108，95% CI [−0.0210, −0.0030]，中介比例 14.5%（校正 M2 基線後 10.1%）。
兩環都顯著：便祕 → M3 負向情緒 β = +0.175 (p = .0001)；M3 負向情緒 → 認知 β = −0.068 (p = .0006)。

**但這條路徑撐不住時序檢驗。** 把暴露換成純粹的 M2 便祕（定義 A，83 例），
**第一環立刻消失：便祕(M2) → 負向情緒(M3) β = +0.024, p = .66**（校正 M2 基線負向情緒後）。
也就是說，定義 B 的第一環之所以顯著，是因為定義 B 把 **M3 的便祕**算進暴露，
而 M3 便祕與 M3 負向情緒是**同一時點**測量的。這是同波共變，不是中介。

**唯一有正確時序的第一環是憂鬱**：
便祕(M2) → 憂鬱(M3) β = +0.510, p = .032（校正 M2 憂鬱基線；定義 B 版 +0.342 SD, p = .016，FDR q = .079）。
**但它的第二環不成立**（M3 憂鬱 → 認知 β = −0.011, p = .098），
中介量 3.8%，bootstrap CI [−0.0102, +0.0007] 包含 0。

> **所以結構與反向因果查證那次的「認知→自理→便祕」一樣：第一環或第二環總有一環斷掉，
> 中介在本資料中沒有任何一條成立。** 其餘三條（M3 失眠症狀 p = .28、M3 長期壓力指數 p = .19、
> M3 神經質 p = .80）第一環就斷。

### 3.4 調節 —— 偵測不到，且已知檢定力不足

19 個交互作用，**FDR 校正後最小 q = 0.450**。
未校正 p < .05 僅工作要求 1 項（β = +0.091 SD/SD, p = .024, q = .450），
且它只有 74% 樣本可用（在職者），不應解讀。

**最小可偵測交互作用（80% power, α = .05）為 0.070–0.113 SD/SD，而主效果本身只有 0.070 SD。**
與既有 20 個交互作用的陰性結論完全一致：瓶頸是暴露僅 188–213 例，
**解法是加病例（Refresher 1＋2），不是再加調節變項。** 本節應合併進既有的 §7.3 檢定力限制，
不要另立新節，否則讀者會以為做了新的實質性檢定。

### 3.5 反向路徑的替代解釋 —— 也不成立

反向路徑（M2 認知 → M3 新發便祕，probit，限 M2 無便祕者，N = 2,012／新發 114）：

| 模型 | 認知 β | p |
|---|---|---|
| 基準（既有共變項） | −0.1835 | .0051 |
| ＋M2 失眠症狀 | −0.1839 | .0050 |
| ＋M2 焦慮整組 | −0.1870 | .0047 |
| ＋M2 負向情緒 | −0.1792 | .0064 |
| ＋M2 長期壓力指數 | −0.1815 | .0061 |
| **＋四類整組** | **−0.1894** | **.0045** |

**完全沒有衰減，加入後反而略強。** 這四類不是反向路徑的替代解釋，
反向因果那一節的結論不受影響，而且多了一組排除證據。

## 四、文獻查證

> **以下文獻除特別標註外，皆僅依題目與摘要層級，引用前須核對全文。**
> 來源：PubMed。

### 4.1 便祕與這四類的關聯：文獻支持，與本研究 a 路徑一致

- **睡眠 → 便祕（有前瞻證據）**
  - Tian 2024 系統回顧與統合分析（J Clin Neurosci 126:12-20）：睡眠障礙與便祕 **OR 1.47 (1.31–1.64)**，
    成人 1.65、失眠 1.94、睡眠不足 1.33、睡眠品質差 1.56。異質性很高（I² 88.8%）。
    [doi:10.1016/j.jocn.2024.05.030](https://doi.org/10.1016/j.jocn.2024.05.030)
  - **Nakagawa 2023（Cureus 15:e46175）：Sukagawa 前瞻世代，1,696 名 ≥75 歲基線無便祕者追蹤一年，
    191 人（11.3%）新發便祕；PSQI 四分位 adj OR 1.57／1.78／2.02，trend p = .003。**
    **這是時序明確的「睡眠在前、便祕在後」證據，對本研究很關鍵：
    它說明睡眠應被視為便祕的上游原因（共同成因候選），而不是便祕的下游後果。**
    [doi:10.7759/cureus.46175](https://doi.org/10.7759/cureus.46175)
  - 睡眠時數與便祕是 **U 型**：Wang 2022 NHANES（n = 14,054），相較 7 小時，
    ≤4 小時 OR 1.54、≥10 小時 OR 1.90。[doi:10.1080/07420528.2022.2139713](https://doi.org/10.1080/07420528.2022.2139713)
    → **本研究把睡眠時數當線性共變項是保守的設定，必要時可加二次項做敏感度分析。**
  - Xiong 2025 NHANES（n = 6,894）：短睡＋久坐並存時盛行率最高 OR 1.975。
    [doi:10.3389/fnut.2025.1548455](https://doi.org/10.3389/fnut.2025.1548455)

- **憂鬱／焦慮 → 便祕**
  - **Zheng 2025 孟德爾隨機化（Arch Med Sci 22:1001-1010）——最該引用的一篇。**
    雙向二樣本 MR：**重度憂鬱 → 便祕 OR 1.28 (1.12–1.46)**，worry OR 1.42；
    **「anxious feelings、睡眠時數、sleeplessness 對便祕皆無因果效果」**；
    **反向分析「便祕對憂鬱、焦慮、睡眠障礙皆無反向因果關聯」**；
    多變項 MR 中只有重度憂鬱的關聯穩健。
    [doi:10.5114/aoms/207613](https://doi.org/10.5114/aoms/207613)
    → **這篇同時支持本研究的三個寫法**：(1) 憂鬱屬上游原因而非下游後果，
    (2) 焦慮與睡眠對便祕可能不具因果性（與本研究 CIDI 焦慮 a 路徑虛無一致），
    (3) 便祕不會反過來造成情緒問題（與本研究中介第一環斷掉一致）。
  - Zhao 2025（Neurogastroenterol Motil 38:e70162）：610 名慢性便祕，
    GAD-7 與 PHQ-9、PHQ-15 為**難治型便祕**的獨立危險因子（AUC 0.81）。
    [doi:10.1111/nmo.70162](https://doi.org/10.1111/nmo.70162)
  - Liu 2025（J Affect Disord 390:119845）：5,499 名 10–18 歲三個月前瞻，
    基線憂鬱 RR 1.65、焦慮 RR 1.64 預測新發功能性便祕，由韌性完全中介。
    **族群是兒少，不可外推至中年。** [doi:10.1016/j.jad.2025.119845](https://doi.org/10.1016/j.jad.2025.119845)

### 4.2 這四類與便祕—認知關聯的角色：**只有憂鬱有一篇前例，且方法學弱**

- **Liu 2025（Front Nutr 12:1578181）——唯一直接做過的一篇，必須正面回應。**
  9,417 名 ≥65 歲無失智者，Rome IV 臨床診斷便祕（盛行率 20.1%）：
  便祕 → MCI **OR 1.177 (1.047–1.323)**、語言 OR 1.133、**執行功能 OR 1.386 (1.130–1.701)**；
  症狀層級：≥3 天一次 OR 1.391、排便困難 OR 1.278、硬便 OR 1.326；
  **「Depression mediated the association of constipation with global cognitive and language function.」**
  [doi:10.3389/fnut.2025.1578181](https://doi.org/10.3389/fnut.2025.1578181)
  - **三個可以用來區隔的點**：
    1. **它是橫斷研究**（單一時點、logistic 迴歸），
       在橫斷資料上做中介無法區分中介與共變，而本研究用九年縱貫、校正基線認知，
       **在正確時序下憂鬱的中介不成立（第二環 p = .098，CI 含 0）**。
       這正是本研究可以提供的增量。
    2. **它的領域型態與本研究相反**：它最強的是執行功能（OR 1.386）、
       本研究最強的是情節記憶（−0.144）。這個分歧值得在討論中處理
       （年齡層不同：≥65 歲 vs 平均 55.4 歲；結果變項不同：二分型認知障礙 vs 連續分數）。
    3. 結果是**篩檢型二分診斷（MCI）**，與 Wang 2025 盤點指出的既有文獻共同缺口一致
       （11 篇認知結果全是 MMSE／MoCA／BIMS 篩檢量表）。
       本研究的 BTACT 多領域連續測驗仍是缺席的格子。
  - **注意：不可把這篇寫成「已有文獻證實憂鬱是中介」**，因為它的設計無法支持該宣稱，
    而本研究在更強的設計下沒有複製出來。

## 五、論文該怎麼寫

1. **新增一節「替代解釋之排除：情緒、睡眠與長期壓力」**，放在第五章（討論）既有的
   「因果方向之雙向檢定」之後，或作為該節的第五小項。
   核心句型：這些因素與便祕有穩健關聯（a 路徑顯著），
   但在本樣本中不預測九年認知變化（b 路徑 FDR 後全虛無），
   因此不滿足混淆的必要條件；全部納入後主效果衰減 0.1%。
2. **第四章新增一張表**：a 路徑 / b 路徑 / 共變項加入後衰減 / 中介量 / 交互作用 q 值 / 最小可偵測效果量，
   六欄一次交代，避免分散成多段文字。
3. **更正既有的逐步調整敘述**：第三步的衰減來自 BMI 與慢性病，**憂鬱貢獻僅 0.2%**，
   不可寫成「調整憂鬱後衰減」。
4. **把「自陳 vs 診斷」的落差寫成實質發現**：A11t 自陳焦慮憂鬱差 0.543 SD，
   CIDI 診斷差 0.009–0.143 SD 皆不顯著。與 `B1SAMPLI` 調整後 p = .051 的既知弱點寫在一起，
   作為「症狀報告傾向」這個限制的量化證據。
5. **限制必須寫明焦慮的測量問題**：MIDUS P1 無焦慮症狀嚴重度量表，
   CIDI-SF 二分型僅 37 例，陰性結果不具資訊量。不能寫成「焦慮無關」。
6. **中介的陰性要寫清楚是哪一環斷**：憂鬱是第二環斷、其餘是第一環斷；
   並說明 M3 負向情緒那條 14.5% 的中介是定義 B 的同波共變假象，改用定義 A 後消失。
   這一段同時替未來審稿人的「為什麼不用定義 B 做中介」預先作答。
7. **調節併入既有 §7.3**，不另立新節；並重申加病例（Refresher 1＋2）才是解法。
